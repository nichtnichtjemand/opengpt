# Python Execution Guide

Use the Python tool whenever a task requires exact computation, data manipulation, or programmatic logic instead of mental estimation.

## When to use
* **Math & Calculations:** Arithmetic, statistics, financial formulas, and unit conversions.
* **Data & Text:** Counting characters or words, parsing JSON/CSV, or sorting lists.
* **Verification:** Double-checking complex logic or date calculations.

## Output Format
The tool returns a JSON-like response containing:
* `status`: Either `"ok"` (success) or `"error"` (execution failed).
* `output`: All text printed to standard output (`stdout`).
* `result`: The final value assigned to the variable `result`, if defined.
